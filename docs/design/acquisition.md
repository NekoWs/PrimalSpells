# 获取方式与敌对施法者

第79轮实现首版“结构战利品＋敌对施法者”。核心模组承担基础战斗遭遇与获取闭环；未来附属模组可扩展敌人和结构。后续方向见[TODO](../todo.md)。

## 1. 探索回报

地点决定法术类别与法杖等级，不按玩家装备动态抬高敌人强度。追加奖励保留原版箱子内容；所有62种已注册法术都有来源，调试杖不进入奖励。

| 奖励池 | 箱子来源 | 法杖等级 | 主要方向 |
|---|---|---|---|
| starter | 村庄神殿 `village/village_temple` | T1 | 入门火花弹、火把、弹跳 |
| ruins | 地牢、废弃矿井、沙漠神殿、丛林神庙、雪屋地下室、沉船宝藏 | T1–T2 | 基础投射物、速度、轨迹、伤害、双重施放 |
| raiders | 掠夺者前哨站 | T2–T3 | 追踪、护盾、冰冻、切割、链锯、缩短充能 |
| arcane | 林地府邸、要塞图书馆/走廊/路口 | T3–T4 | 触发、定时、治疗、水晶、远距与空间控制 |
| nether | 下界要塞、堡垒遗迹宝藏/普通/桥梁/疣猪兽棚 | T4–T5 | 爆炸、等离子、穿刺与后坐力修正 |
| relic | 远古城市、末地城宝藏 | T5–T6 | 汇聚之光、黑洞、复制、多重施放、量子纠缠 |

- 村庄神殿箱：保证一根装好火花弹的T1普通法杖、一张入门散卡和《寻法手记》。并非所有村庄都有神殿。
- 其余匹配箱：保证两张对应池散卡，40%概率附带成品法杖。等级在该池范围内均匀抽取，成品有1/8概率为蓄能型，使用原有等级/变体数值。
- 成品杖有真实唯一wandId、已装配法术、完整槽位组件、满法力。生成时掷出数值并存档，拿到即可使用、拆改，不共享模板实例。
- 手记说明操作、地点类别、术士应对和夺杖；目前没有坐标定位、委托、保底收集或新合成配方。
- 已生成过战利品的旧箱子不会重掷；未开启且仍保留原版LootTable的箱子可走当前生成规则。结构标签对已有结构元数据同样有效。

## 2. 游荡术士

`primalspells:rogue_mage`是核心敌人，首版复用原版唤魔者外观并显示实际手持法杖，不宣称已有独立美术或多种敌人流派。

自然生成仅限以下真实结构piece内部：

- ruins：沙漠/丛林神庙、两类废弃矿井。
- raiders：前哨站、沼泽小屋。
- arcane：府邸、要塞。
- nether：下界要塞、堡垒遗迹。
- relic：远古城市、末地城。

村庄、雪屋、沉船与普通地牢只提供箱子奖励，不新增术士。使用原版MONSTER预算、地面条件及非和平限制；向原候选表追加权重35、单人组，不替换原有敌人。当前允许符合条件的明亮结构内生成。它不是袭击成员，不组织野外巡逻，不拆门或方块。

术士36HP、12经验，出生携带所在地配方与等级的真实法杖。准备20t后点射三次，点射间隔至少12t，受法杖法力/冷却限制；整轮后恢复45t。18格内有视线才施放，距离超过14格或被遮挡时寻路。准备有声音与举杖动作，受到有效伤害会打断；创造/旁观玩家不作为攻击目标，目标离出生区域24格后停止追击。

所有伤害、护盾、触发荷载、反弹、自伤、耗蓝与冷却都使用现有法术机制，不另写敌人专用命中规则。死亡通过原版装备掉落保证掉出正在使用的整根法杖，保留wandId、掷点与法术，没有再额外复制一根奖励杖。

结构可反复遭遇，首版也可能被刷怪场利用。当前没有反自动化惩罚、一次性清空结构或精英挑战系统；遭遇密度、重复挑战与奖励节奏需要生存体验后继续调整。

## 3. 世界安全边界

沿用现有战斗法术不破坏方块的规则，保留生命伤害和既有自伤判定。生成限制与追击范围用于约束遭遇，不是领地保护系统；在指定结构内部建基地仍可能遇到当地怪物。

未来世界作用优先采用探测、照明、搬运与救援等非破坏性交互。红石联动、领地授权和整合包事件接口尚未实现，记录在TODO，不以当前结构标签冒充完整接口。

## 4. 数据与接入

- `loot/SpellLootProfile.kt`：地点等级、散卡池和成品配方；当前内容为代码定义。
- `loot/SpellLoot.kt`：调用现有物品/法杖工厂创建奖励与手记。
- `loot/ExplorationLootModifier.kt`和`registry/ModLoot.kt`：NeoForge全局战利品修改器，追加奖励。
- `data/primalspells/loot_modifiers/*.json`：六个条件配置，`profile`引用上述池键；整合包可覆盖条件、优先级和配置。
- `data/primalspells/tags/worldgen/structure/spell_sites/*.json`：五个术士地点标签，可覆盖/追加结构。标签改变生成地点，不能独立新增卡池。
- `event/SpellcasterSpawns.kt`：原候选表追加；`entity/RogueMage*.kt`为实体与AI，客户端仅注册渲染器。

NeoForge26.2自动发现loot_modifiers目录中的全部JSON；不再创建旧版`data/neoforge/loot_modifiers/global_loot_modifiers.json`索引，否则会把索引当成GLM本体解析并报缺少type。

## 5. 验证与试用

`exploration`实机夹具通过真实`/loot`验证六类箱子、无关箱反例；检查62法术来源、144根唯一成品杖与存档还原、结构标签、真实结构元数据内追加候选及野外反例。战斗对象为真实生存玩家，检查准备、伤害、掩体、打断、原手杖唯一掉落与收场零残留。

手动试用：`/loot give @s loot minecraft:chests/village/village_temple`领取入门箱奖励；`/summon primalspells:rogue_mage`生成基础配方术士。实际自然结构刷怪密度、多人体验与整套生存进度仍待人工验收，见[verify](../issues/verify.md)。构建与录像结论见[build-and-run](../build-and-run.md)第79轮。
