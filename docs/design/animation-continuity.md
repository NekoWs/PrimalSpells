# 动画连贯性

## 目标与语义

入场从隐藏或零尺寸展开，退场从当前形态接续并到零；重复触发、重定向和切杖不先回满尺寸、不重置已经开始的离场。正常回收先完成有限动画，死亡/换维/世界卸载允许立即清理。

动画要说明正在发生的事：爆炸持续向外扩张，晶体爆碎、盾片外飞，吸引场可向内收束；单片熄灭不等于把整个爆炸轮廓缩回去。提高表现力靠轮廓、节奏、方向和有限色阶，不靠遮满视野的细碎光点。

## 当前接线

- 出生包透明，PD程序首次接管原子设置位置/尺寸/颜色两端；脚下法阵和冷却层从零展开，避免切杖首帧满尺寸。
- 持杖主阵presence用8t线性退场，片元尺寸presence^0.75，再retire等待PD完成；独立冷却会话各自收尾，不粗暴删除旧会话。
- 拖尾Emitter停发后已有粒子按SCALE+ALPHA寿命曲线结束，保留4t下限；固定RGB硬边不变。
- 水晶白闪以PD的1t颜色接续变化，临爆节奏加快；到期真实爆炸而非只删视觉。
- 光束用本刻真实扫掠/护盾接点画段，命中后不再沿旧路径延伸；连锁魔弹只画本次跃迁，不在旧击中点抖动长尾。

## 照明也是动画的一部分

目标是照明强度与出生/退场同相位，尺寸归零后不残留满光，正常删除不整屏亮度硬切。glowing免环境光不等于动态光强。

PD 1.0.21已提供随alpha/尺寸包络变化的照明及独立LIGHT曲线，particle_lighting四项检查通过，缩片结束不再残留满光。固定尺寸无曲线粒子及直接删除路径仍需逐法术补齐入退场声明，见 [open](../issues/open.md#发光效果完整接入)；没有宣称升级依赖即完成所有效果的全局改造。

## 第一人称与镜头

杖首idle由原生模型模块承担，不用眼锚粒子伪装手骨。中央准星留空；冷却状态融入地面三角形和HUD。第一/第三视角及不同FOV必须分别验收。

CameraImpulse是两端偏移与速度为零的有限曲线，叠加不重置旧相位，tanh连续限幅：偏航≤0.45°、俯仰≤0.65°，不改翻滚/FOV。原版受伤视角强度为0时关闭。黑洞只形成时近场轻触；爆炸限定近场，边缘平方衰减。登出/跨世界清有限脉冲。

## 验证

纯曲线调用实际CameraImpulse检查端点/连续性/限幅。视觉用相关原生场景保留原帧和数值，不用服务器状态代替上屏证明；20FPS视频不能单独证明高刷连续性。

短退场门槛：95%→5%跨3～10帧、最大单帧覆盖下降≤35%、清零前覆盖≤10%。混合场景需按真实事件分ROI，不为通过而放宽阈值。未通过项见 [open](../issues/open.md)，自然地形/多人范围见 [verify](../issues/verify.md)。
