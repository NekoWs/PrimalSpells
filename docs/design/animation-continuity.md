# 动画连贯性（第61轮，2026-10-09）

## 目标模型

动画从当前形态接续，起落两端连续；停止施法/放下法杖时先完成有限退场，再删除成员。
MC实色大颗粒保持不透明，尺寸与运动表达力量；不通过半透明膜占满第一人称视野。
卸能、回洗充能、受击/破口、区域施力应有不同的方向与时间语义。

## 现有能力与接入范围

PD ParticleLifeCurve支持单片逐帧尺寸曲线，Builder/SpawnSpec/Emitter均可声明；本侧只提供关键帧。
护盾玻璃/碎片、电弧、爆炸火星/烟团、通用碎屑、重力落点、拖尾与死亡余痕接入从0展开、保形、收束到0。
护盾的位置仍沿命中方向展开/碎裂，单片尺寸收尾不把整块面板缩向球心。

固定黑洞/重力场/晶体/冰壳/斥力主体，停止直接remove，完整结构追加有限缩放收尾并保留销毁余量。
场结束时剩余运动批次交给PD有限组收束，不维护替代粒子集合。
光束取消32分之一格位置量化，按束端方向散开并缩片收尾；停止后的销毁发生在收尾之后。
爆炸白热核→移动火团→冲击圈→烟团相互重叠，火团不再在移动半程被删掉。

**未完成的严格保证**：PD组ScaleBy未继承当前倍率，Fixed轴心/热更空间变量不插值，Emitter锚点外推与track头部不同相位。
因此停止组级零尺寸入场与锚点插值接入，未实现的部分登记在[PD需求](../issues/pd-api-requests.md)最后两条。
固定结构仍沿用出生形式；脉冲/多倍率中断、移动帧间连续性不能声称完全解决。不得复制播放器或改前置jar绕过。

## 法杖引导与第一人称

- 脚下三角符阵逐段建立、轻微悬浮；放下时颗粒浮起收束，350ms内收完，400ms销毁。
- 常驻菱形符印移到宝石外侧，随左右手镜像，减少横向扩张；不跨过准星，不周期关闭可见性。
- 白色束印表示施放后的卸能恢复，快速展开后按真实持续时间回位；蓝色导晶自下而上连续充亮，表示牌堆回洗充能。
- 冷却仅在开始声明起点/持续时间，PD逐帧推进，结束保留200–245ms收尾；连续施法各轮独立起落，旧提示不被切零。
- 模型余光用16级材质，1tick升亮/6tick收尾；重复施法继承当前亮度，结束精确归零。
- 施法方粒从宝石沿真实发射方向展开，无额外延迟。瞄准和防重新举杖机制保持已有实际行为。

## 镜头冲击

CameraImpulse纯时间曲线两端偏移与速度为零；叠加新冲击不重置旧相位，合成经过连续tanh限幅。
偏航上限0.45°、俯仰0.65°；不改变翻滚/FOV。玩家受伤视角晃动强度设0时完全关闭。
黑洞取消每tick持续重锤，仅形成时6格内轻触；爆炸作用半径2R+3、振幅min(0.55,0.06R)，边缘平方衰减至零，旁观者不触发。
登出、跨世界清除有限脉冲，避免旧镜头状态进入新世界。

## 验证

构建：`./gradlew build --console=plain`。
纯曲线测试：`tools/verify/CameraImpulseCheck.kt`调用实际CameraImpulse，对4–16tick时长检查端点、端点速度、每毫秒连续性、角度限幅、叠加起点。
全量实机：19场覆盖区域场、护盾、爆炸、各新增法术、联动、法杖第一/第三人称和瞄准。
火球拖尾退场使用真实死亡tick33–65独立窗口，避免t30相机越过墙体的遮挡被误报为死亡硬切。
冷却入场检查施法后前三tick逐步展开，禁止靠瞬间满尺寸来通过“下一tick完整”的旧门禁。
第一轮发现PD多段缩放重置，已停止该接入；第二轮暴露测试取样问题与黑洞过快收尾。
修正：黑洞结构500ms收束、剩余星尘600ms收束；弹体死亡碎屑增加可读性；高速炸弹在pendingAdd flush之后、首次移动之前保存真实对象，避免提前命中导致断言缺失。
最终证据合并61b的10条未变场景、61c的8条动画复验与61d的联动复验，来源记录`build/capture/runs61.tsv`。
共3529帧/零丢帧/168项游戏内断言通过，19场逐帧视觉门禁全部PASS。实际CameraImpulse纯曲线260078项检查通过。

火球主体最低可见性门槛保持不变，单独的死亡碎屑窗口使用368px最低可读覆盖，避免要求余痕与弹体占屏同样大。
