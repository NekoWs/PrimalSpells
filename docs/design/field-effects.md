# 区域法术视觉（2026-10-08，第 49–51 轮）

> 第53轮已改为MC实色硬边方粒；下面早期柔光/alpha渐隐说明仅供历史参考，当前规范见 [minecraft-visuals.md](minecraft-visuals.md)。
## 目标与能力

黑洞从稀疏球面点阵改为「暗核 + 旋转吸积盘 + 螺旋吸入」；重力场从球壳与雪点改为
「球形边界 + 下压波面 + 地面井环」。保留 Minecraft 的小粒子尺度，亮度集中在结构的内缘和方向标记。
玩法半径、迟缓等级、实体与投射物施力、法力和存活时间均保持原值。

PD 1.0.14 已提供所需能力：`ParticleStyle.SOFT_DOT/LINE`、`ParticleVisual`、`Draw.curve/polyline`、
`ParticleGroup.spin/fadeIn/scale/fadeOut` 与 `ParticleBatch.setVelocityAll/removeIf`。
跟随采用 `ParticleGroup.setPivot`；两层外环由 `expression` 逐帧求值，
`setVariableLive` 更新场心和整体滞后向量。所需能力已具备，无新增 API 缺口。
用户明确暂不要求按玩家视角变化；不实现屏幕折射或新的粒子系统，不升级前置。

## 黑洞

`BlackHole` 保留引力结算与镜头呼吸，三个视觉钩子委托每次施法独立创建的 `visual/BlackHoleFx`。

- 暗核半径 0.65（第 50 轮从 1.05 缩小约 38%）：160 个小柔边暗粒子密铺球面；尺寸 1.4，
  保留小颗粒遮挡盘后半部的造型。内盘外半径为 2.33/2.53 格，外环半径 2.7/3.25 格。
- 双层吸积盘：固定倾斜平面，每层三条螺旋；内缘亮紫、外缘暗紫，两个组以不同速度同向旋转。
- 核边亮带：128 颗小光点成细环，替代第 50 轮的交叉上下弧，消除笼架状光弧穿核的观感。
  仍是空间粒子造型，不扭曲背景，也不按观察者方向求值。
- 移动：暗核、内盘、核边亮带和范围星点以 `setPivot` 跟随最终场心，不重建成员或重置自转。
  两层外环共 320 颗；滞后按 `(上一滞后 − 本 tick 位移) × exp(-0.35)` 更新、长度上限 1.1 格。
  外环沿滞后方向最多拉长 65%，环心稍落后于暗核；急停后指数回圆，反向时拉伸方向平滑翻转。
  单 tick 位移超过 4 格按瞬移处理，清零滞后。三维方向均可形变；这是视觉惯性近似。
- 五格范围：64 颗低亮边界星点。每 tick 三颗星尘，黄金角与缓存的球面方向确定发射位置；
  速度按 `v × 0.9 + 向心加速度` 递推，由 PD 积分，进入暗核即回收。
- 进场：核 6 tick、盘 10/13 tick、边界 14 tick 淡入；退场：原组继续旋转着收缩，12–18 tick 淡出。
  无重建壳体、反弹小球或本侧延迟收尾任务；PD 按淡出指令销毁整组。

固定结构 1272 颗（暗核160 + 内盘600 + 核边128 + 外环320 + 边界64）；星尘有 60 tick 安全寿命，通常提前进入暗核。
静止且惯性恢复后固定结构零逐 tick 更新包；移动时更新组轴心与外环整体参数；星尘保持一次批量速度包/tick，集合与寿命由 PD 管理。

## 重力场

- 四条断开的球面经线与顶部发源环，528 颗低亮青蓝柔边点，保持五格球形边界。
- 加速落体由白色方点改为短青蓝细线，初速仍为零、恒定下落加速度仍为 0.01。
- 每 13 tick（12 tick 冷却后下一 tick）下压一层波面：160 点环 + 八个向下尖刻度，
  第一层 13 tick 落地，后续 26 tick；落地仍触发短命溅射，已结束的组引用及时移出列表。
- 场心移动时，球壳更新轴心；重新探测场心下方地面，并平移地面井环。
  已发射的落体、下压波与落地溅射保留发射位置，形成来路留痕，不把历史粒子拉回场心。
- 地面井环改为双环与 24 个刻度，376 颗。半径取球体截面并限制在 3–5 格，
  三格下限是视觉投影，不参与玩法范围或命中。
- 结束时撤销未落地溅射、回收落体/溅射/波面；固定边界与井环 10 tick 淡出。
  `Trajectory` 的共用退场余晖仍正常播完。

固定结构 904 颗，每层波面 176 颗，通常同时存在不超过三层；
落体仍为每 tick 两颗、100 tick 安全寿命，落地提前回收。静止时固定结构无逐 tick 位置更新包。
维度达到 PD 上限时允许少颗粒，不在本模组另做补量或句柄簿记。

## 跟随阶段与同类检查（第 51 轮）

`AreaFieldEffect` 原先默认 MODIFIER，早于 Move/OVERRIDE 读取位置；即使逐 tick 平移结构，
也会落后轨道修正。现在统一声明 VISUAL，在最终定位之后读取场心，范围结算与视觉使用同一位置。
实体/其他弹体所受力和迟缓参数保持原值，本效果不更改自身位移输入。

同类检查：重力场固定球壳/井环存在同样的出生点绑定问题，已修；`Trajectory` 已在 VISUAL 阶段
更新头部 track 和发射器锚点，尾迹保留历史位置是设计行为；护盾粉色破口已绑定持有者实体，
受击玻璃/碎片与爆炸保留发生位置是设计行为。

新增 `black_hole_moving` / `gravity_field_moving` 固定机位回归场景，经真实施法与 OVERRIDE 定位：
先静止，再右移、急停、反向左移、停住，最后正常死亡；检查区域效果在 OVERRIDE 之后执行。
