# 区域法术

## 黑洞

视觉只有0.65格暗核、5格稀疏星点边界和动态吸入星尘；没有固定环、吸积盘或椭圆外环。暗核与星点通过Movable世界朝向轴心跟随本体，粒子批量速度交PD处理，不自管积分或拆包。

主体由零尺寸短展开，结束时暗核/边界收束、余下星尘逐片缩小，保持向内运动。只在形成时给近场轻冲击，没有范围内持续抖屏。

玩法由AreaFieldEffect在原维度每刻结算：半径5格、向中心力度0.6/(距离+0.5)，除目标质量；核心1.15×areaScale内每刻4点重力基础伤害，不加向外击退，允许自伤。吞弹储能在结束时释放爆炸，场源间牵引而不互吞。黑洞质量256，创造飞行者不受吸引。

## 重力场

蓝色方点经线/范围、下压波面、地面井环和下落片元组成稳定场。已发射波面留在来路，当前范围与井环跟随本体最终位置，地面高度也交PD相邻样本插值。退场撤销未完成落地喷发，落体/溅射沿原运动逐片收尾。

每刻施加下压/迟缓，实体离开或场结束即撤销本场效果。质量32，投射物所受外力除自身质量；静态源无碰撞但可被运动修正和外力带动。

## 维度、接口与验证

区域场首tick捕获level，不能追读已跨维度施法者的新世界。吸引/下压力属于玩法，成员簿记、位置积分、插值和曲线属于PD； API规则见 [effects-api](effects-api.md)。

black_hole、black_hole_moving、gravity_field、gravity_field_moving检查真实施法、移动跟随、入退场和零残留；spell_stability覆盖双场持续运动与大批量速度通路。自然地形/多人压力验收见 [verify](../issues/verify.md)。光照生命周期仍被PD缺口阻塞，不把尺寸收束写成光场平滑。
