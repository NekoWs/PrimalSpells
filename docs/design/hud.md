# 魔法HUD与布局编辑

按用户提供的参考图采用硬边像素晶石、银色镶框与紫色分格符印。游戏内只用图标、数字和进度，不显示“充能中”“冷却中”等状态句；设置界面保留操作说明。绘制使用原版GUI，世界粒子继续由ParticleDrawing管理。

命中/击杀采用已选定的A星芒：命中为短促紫白十字，击杀为红色斜十字，只有连续的短尖芒向外淡出，不附加碎粒、离散亮点或光晕。以最近命中的目标区分反馈，同一目标的连击不会堆叠，命中多个目标才显示多个完整的小星芒。

## 状态语义

| 组件 | 默认位置与表达 |
|---|---|
| 法力 | 快捷栏左上方，青色晶石、当前/上限数字与进度。低于15%或刚才失败的法术仍无法付费时变红；恢复足够法力后解除不足标记 |
| 双冷却 | 快捷栏右上方，两行独立出现：白色沙漏表示施放恢复，紫色晶石表示牌堆充能。数字均为剩余刻，分格条从空到满；结束短暂退场 |
| 命中 | 准心外围分散的小型完整紫白十字：内侧稍厚、外端尖细，与原版准星留空；每个目标只占一个位置 |
| 击杀 | 准心外围完整的小红色斜十字，在该目标的命中位置平滑接续，和其它目标各自播放；没有数字、晶石或连杀计数 |
| 受击 | 准心外围像素裂纹弧段和内侧晶齿，随原版hurtTime缓动起落；方向默认开启，关闭方向后显示四段通用受伤弧 |

HUD随原版F1隐藏界面一起隐藏，录制非HUD场景也遵守同一入口。手持法杖时显示法力，放下后短退场；切换法杖的首帧从隐藏起步。所有缓动按游戏时钟与partialTick求值，避免不同帧率下速度不同。双冷却读取服务端真实剩余/本次总时长；准心菱框与进度条已删除，不重复显示牌堆充能。拿起8刻仍由世界法阵表现。主手/副手优先级与服务端一致。

命中6t、击杀8t，都从透明开始，0.6t升亮，分别用0.8t/1.5t描出短尖芒。命中从1t起、击杀从2t起平滑淡出；2t后整枚星芒持续向外移动最多2个局部像素，到期完全透明。同一目标在当前反馈存续期内的重复命中不新增、不延长、不重置动画；到期后再次命中可重新提示，持续攻击单个目标始终最多一枚星芒，不用笔画数量表达伤害次数。

命中不同目标，各自分配固定位置：使用低差异角度在准星外围错开，每枚反馈都有自己的中心和完整轮廓，不把多组笔画沿同一条射线排列。位置限制在小范围内，后来的目标不会挪动旧标记。命中和击杀共享占位；某目标被击杀时保留原标记身份、位置及外移进度，用0.8t将命中残影淡出并接入红色斜十字，不为该目标多算一个标记，也不隐藏其它目标的命中。

隐藏界面/暂时放下法杖不暂停年龄，恢复时不会补播过期反馈；放下法杖短退场期间也继续正常求值，退出世界清空队列。反馈只有有限寿命的细短笔画，不散出碎粒。极多不同目标同时受击时的辨识仍需体验验证。

受击弧在外围独立显示。所有反馈仍属于手持法杖HUD。受击方向来自原版hurtDir；法术因no_knockback跳过的原版方向通知由SpellImpact补回，使用反向传播向量，零水平传播时退回施法者位置，不新增击退。

受击弧为1GUI像素笔画。每枚命中/击杀星芒最长7个局部像素，每臂最多3格，靠近自身中心的笔画厚2格，外端收为1格。标记中心按ceil(10/布局缩放)+5定位在方形安全边界外，再做不超过数格的错位和外移；原版15×15GUI像素准星及外围至少2GUI像素空隙始终留空，缩小反馈也不侵入准星。

## 可视化设置

- 游戏中按 **H**（原版按键设置中可重绑），或模组列表→PrimalSpells→配置。
- 法力、双冷却、准心反馈三块分别拖动，靠近屏幕中心时吸附；滚轮每格调整5%，或拖选框右下角改变大小。方向键微调1GUI像素，Shift+方向键10像素。旧配置focus键继续保存准心反馈位置，不丢弃原布局。
- 缩放范围60%～250%。位置保存为屏幕归一化中心；窗口、GUI倍率改变后重新限制边界，避免丢到屏幕外。
- 编辑器复用实际HUD绘制，以68/100等固定数值预览；可开关命中反馈及受伤方向。重置只修改草稿，保存成功才生效，取消/Esc丢弃本次修改。
- 本机配置为`config/primalspells-hud.json`，不随服务器/世界同步。原子替换保存；损坏配置保留原文件并采用默认值，保存失败在界面显示且不关闭。

## 接线边界

`client/hud/HudLayout.kt`管理布局和本机JSON；`WandHudPainter.kt`共享正式/编辑预览绘制；`WandHudRenderer.kt`管理客户端缓存和事件；`HudImpactAnimations.kt`按游戏时间管理独立命中/击杀动画；`client/screen/HudEditorScreen.kt`管理原生Screen输入。

`SyncWandStatsPayload`包含equipRemaining/equipTotal/manaBlocked；手持杖每刻同步，背包其它杖仍按20刻节流。当前网络协议1.6.0，客户端和服务端需要使用同一版。`HudImpactPayload`携带目标运行时ID（VarInt）和击杀标记，将实际接受的非治疗、非自伤命中回报给玩家施法者；去重只作用于客户端HUD，不减少真实伤害、穿刺或触发次数，也不要求目标实体仍在客户端存活。退出世界清数值与动画，保留本机布局。

`magic_hud`使用真实伤害及网络回报，检查同一目标每刻16次连击只显示一个标记、三个不同目标分别显示三枚星芒、其中两个被击杀后只保留一枚命中和两枚击杀。像素验收覆盖完整轮廓、独立包围框、中心不共线、准星保护区、有限外移与严格淡出；`HudImpactChecks`额外覆盖按目标合并、击杀接续、持续单目标攻击不堆叠、128个不同目标、不同布局缩放及退出清理。

原生回归57项机制检查通过，200帧零丢帧；三个目标各自的星芒包围框为21×21屏幕像素（GUI倍率3），准星保护区变化像素为零。击杀像素能量95%→5%跨5帧，最大单帧损失25.8%，清零前6.1%，不放宽退场门禁。

录制方式见 [构建与运行](../build-and-run.md)，证据在`build/capture/out/magic_hud`；未覆盖范围见 [verify](../issues/verify.md)。不同整合包HUD叠放、自然日光、极密集反馈的可读性及多人接受度仍需体验验证。
