# 魔法HUD与布局编辑（第81轮）

按用户提供的参考图采用硬边像素晶石、银色镶框与紫色分格符印。游戏内只用图标、数字和进度，不显示“充能中”“冷却中”等状态句；设置界面保留操作说明。绘制使用原版GUI，世界粒子继续由ParticleDrawing管理。

## 状态语义

| 组件 | 默认位置与表达 |
|---|---|
| 法力 | 快捷栏左上方，青色晶石、当前/上限数字与进度。低于15%或刚才失败的法术仍无法付费时变红；恢复足够法力后解除不足标记 |
| 双冷却 | 快捷栏右上方，两行独立出现：白色沙漏表示施放恢复，紫色晶石表示牌堆充能。数字均为剩余刻，分格条从空到满；结束短暂退场 |
| 命中 | 准心位置短促紫白魔法十字：紫色外棱、白色内刃、四端晶齿，中心留空；只在接受伤害后出现 |
| 击杀 | 准心位置红色斜十字，覆盖普通命中十字；没有数字、晶石或连杀计数 |
| 受击 | 准心外围像素裂纹弧段和内侧晶齿，随原版hurtTime缓动起落；方向默认开启，关闭方向后显示四段通用受伤弧 |

手持法杖时显示法力，放下后短退场；切换法杖的首帧从隐藏起步。所有缓动按游戏时钟与partialTick求值，避免不同帧率下速度不同。双冷却读取服务端真实剩余/本次总时长；准心菱框与进度条已删除，不重复显示牌堆充能。拿起8刻仍由世界法阵表现。主手/副手优先级与服务端一致。

命中6t、击杀10t，出生0.6t、最后2t退场；连续命中延长结束时间，不重置已经出现的入场，避免机枪每刻从隐藏闪现。击杀优先于普通命中，受击弧在外围独立显示。所有反馈仍属于手持法杖HUD。受击方向来自原版hurtDir；法术因no_knockback跳过的原版方向通知由SpellImpact补回，使用反向传播向量，零水平传播时退回施法者位置，不新增击退。

## 可视化设置

- 游戏中按 **H**（原版按键设置中可重绑），或模组列表→PrimalSpells→配置。
- 法力、双冷却、准心反馈三块分别拖动，靠近屏幕中心时吸附；滚轮每格调整5%，或拖选框右下角改变大小。方向键微调1GUI像素，Shift+方向键10像素。旧配置focus键继续保存准心反馈位置，不丢弃原布局。
- 缩放范围60%～250%。位置保存为屏幕归一化中心；窗口、GUI倍率改变后重新限制边界，避免丢到屏幕外。
- 编辑器复用实际HUD绘制，以68/100等固定数值预览；可开关命中反馈及受伤方向。重置只修改草稿，保存成功才生效，取消/Esc丢弃本次修改。
- 本机配置为`config/primalspells-hud.json`，不随服务器/世界同步。原子替换保存；损坏配置保留原文件并采用默认值，保存失败在界面显示且不关闭。

## 接线边界

`client/hud/HudLayout.kt`管理布局和本机JSON；`WandHudPainter.kt`共享正式/编辑预览绘制；`WandHudRenderer.kt`管理客户端缓存、动画和事件；`client/screen/HudEditorScreen.kt`管理原生Screen输入。

`SyncWandStatsPayload`增加equipRemaining/equipTotal/manaBlocked；手持杖每刻同步，背包其它杖仍按20刻节流。协议版本升至1.1.0，客户端和服务端需要使用同一版。`HudImpactPayload`只将实际接受的非治疗、非自伤命中回报给玩家施法者，不修改伤害结算。退出世界清数值与动画，保留本机布局。

实机证据与已知限制见[构建与运行](../build-and-run.md)第81轮；不同整合包HUD叠放、自然日光及多人接受度仍需体验验证。
