# 像素视觉规范

## 粒子与材质

采用MC大颗粒感、硬边方形、固定RGB色阶，默认不透明；不以小粒子堆叠细节，不用SOFT_DOT柔点、渐变半透明膜或additive叠亮。

飞行拖尾是明确例外：保持SQUARE硬边和原色阶，允许单颗寿命alpha渐淡并收细。其他效果优先用方向、尺寸与分批燃尽表达；照明强度的过渡独立于片元透明度，缺口见 [PD需求](../issues/pd-api-requests.md)。

glowing用于魔法核心/边界免环境光，烟尘等保留世界受光。造型规则见 [法术质感](spell-quality.md)，动画首尾见 [连贯性](animation-continuity.md)。

## 法术卡图标

类型框必须保留：投射物（含静态投射物）为橙红边框，修正为蓝边框，其他抽牌控制卡保留原紫框。生成器读取已注册类的继承链决定类型，不用旧的手写分组判定，避免锯片、治疗弹或多重施放被分错类。

全部注册法术统一采用16×16圆形类型框与12×12主体原稿：无抗锯齿，alpha仅0/255，主体2～7种实色，边框额外使用4种实色。法术ID、物品模型、语言键和玩法数值不变。

`tools/spells/pixel_icons.py` 保存12×12逐像素主体，每字符一个像素；卡牌同族使用原尺寸整数坐标绘制。`python -B tools/spells/generate_icons.py` 的registered_categories读取注册与继承关系，决定类型框颜色，缺稿或多稿直接报错，不回退旧画风。仅在尺寸或像素实际变化时写资源，避免PNG编码差异污染提交。输出全目录预览 `build/verify/spell-icons-mc.png` 和六张样例 `build/verify/spell-icons-selected.png`；同时检查放大图与原生16px物品栏。注册数量以ModSpells/SpellRegistry为准。

### 图标表达与样例

类型框之外，主体只表达本法术的行为，不加无关封印片、宝石或碎屑。火球为火焰，锯片为连续锯盘，穿刺用投射物贯穿绿色史莱姆表达：保留方形身体与眼睛、两侧可见的贯通弹道，不表达穿墙。黑洞突出深黑暗核与不对称旋入的紫蓝亮边。汇聚之光为斜向延伸的细长白金光迹，避免实心三角或大于号；颜色对照ConcentratedLightFx白光脊RGB(255,253,233)与金色侧线RGB(255,204,88)。

同族图标遵循以下表达，避免把机制画成相同的星芒：

| 同族 | 表达 |
|---|---|
| 多重施放 | 双重为两张完整、错位分开的空白卡；三至五重逐张展开，全量带抽尽牌堆的箭头；不画元素或弹道 |
| 单卡复制 | 紫色叠印卡配2/3/5/10数量，区别于多链抽牌 |
| 附加荷载 | 一张载荷卡搭配史莱姆接触、计时钟或流尽的沙漏，区分触发时机 |
| 轨迹修正 | 青白轨迹直接表示反弹、曲线追踪、往返、蛇形、加减速和散射 |
| 晶体与光束 | 晶体使用实际薄荷绿色；激光为短光脊，等离子束保留紫色发生源，聚光保留白金色 |
| 范围与被动 | 爆炸突出橙黄外爆，吸引与斥力方向相反；护盾、治疗、火把分别保留盾面、十字、火焰轮廓 |

[完整目录](references/spell-icons-all.png)与[重点贴图](references/spell-icons-native.png)由生成器直接放大真实16px资源，旁边保留原尺寸。[原版物品栏第一页](references/spell-icons-inventory.png)、[第二页](references/spell-icons-inventory-2.png)、[第三页](references/spell-icons-inventory-3.png)来自spell_icons原生录制，不使用自绘界面或概念图拼接。78张图标的尺寸、硬透明、色数、类型框、主体唯一性、生成幂等性及JAR内字节均检查通过。三页录制144帧、零丢帧、5项物品同步/清理检查和画面/日志门禁通过。复验命令见 [构建指南](../build-and-run.md#9-实机录制流水线)。

原始概念对照：[A 遗迹石刻](references/spell-style-a-relic-carvings.png)、[B 秘典墨绘](references/spell-style-b-grimoire-ink.png)、[C 晶质珐琅](references/spell-style-c-crystal-enamel.png)、[D 黑曜封印](references/spell-style-d-obsidian-seals.png)。概念图由内置imagegen生成，提示词、参考图及命名备选见 [提案清单](references/spell-style-proposals.json)；它们不是真实游戏贴图。参考用户提供的Noita图标语义与像素密度，不直接复制素材或像素布局。

不得通过缩小高分辨率插画代替逐像素设计。显示名仍未改动，命名备选为短名术式、清晰奇幻、遗物铭文；保留穿刺、反弹、治疗等通用机制词，区分多链同时施放、单卡复制和独立荷载。

## 模型与界面

法杖采用暮紫封印造型：分面黑曜杖身、骨白封印片、紧凑开放式折臂和紫晶，保留细节且遵守游戏面光照；自带粗像素图集、原生模型帧idle和宝石离散亮态，不用写实贴图/独立渲染层。资源见 [wand-materials](wand-materials.md)。

HUD采用原版GUI硬边晶石、银色框线、沙漏与紫色分格，只显示图标/数字/进度；命中/击杀笔画短细、中央留空。规则见 [HUD](hud.md)。

## 验收

资源检查尺寸、alpha、色数、逻辑像素对齐与打包一致；视觉检查自然背景/第一人称、最低可见覆盖、入退场与零残留。构建和相关录制后提交Git，不能用风格变化为日志错误或动画硬切豁免。
