# MC 法术视觉规范（第53轮）

用户要求整体符合 MC 风格，不使用渐变半透明粒子；同时重画此前的法术贴图。
本文件覆盖 field-effects、spell-expansion 和 effects-api 中第49–52轮关于柔光、加色和alpha渐隐的旧观感要求。

## 实色方粒

- 粒子统一采用 PD 的 `ParticleStyle.SQUARE` 或无贴图默认方形，边缘硬，不使用 SOFT_DOT/LINE 的柔边贴图。
- RGB采用固定色阶，alpha为255/1；不添加透明度曲线，不使用 fadeIn/fadeOut 或 additive。
- 全亮仅用于魔法火花/边界；灰色爆炸尘屑随世界光照。全亮不等于加法混合。
- 退场通过尺寸收缩、外飞、错开的有限寿命或定时销毁。PD负责动画、插值和寿命，本侧不实现粒子引擎。
- 第54轮用户授权改变机制并强化表现，最新以 [spell-quality.md](spell-quality.md) 为准；第53轮下表和证据仅记录历史版本。

## 44张法术卡图标

所有已注册法术均重新绘制：32×32逻辑像素，以最近邻放大到64×64；无抗锯齿，alpha仅0/255。
金色边框区分投射物、紫色边框区分修饰器；主体图案与机制对应，色板有限。
覆盖注册表44个id，未改法杖、法术包和木桩图标。复用现有模型/物品定义，不改变id与存档键。

重建：`python tools/spells/generate_icons.py`，输出预览 `build/verify/spell-icons-mc.png`。
预览同时展示64px图案和16px物品栏尺寸。图案为本项目原创，不使用原版/Noita图像素材。

## 验证与提交

构建执行 `./gradlew build`；实机全场执行 `pwsh tools/capture/capture.ps1 -Scene all`。
录制保留分辨率、丢帧、玩法、末尾零粒子、最低可见覆盖量门槛；原alpha渐隐判据改称
“实色颗粒逐步收缩/分批结束”，同样检查覆盖量50%到5%的时间跨度。
运行日志异常仍作为独立门禁，不能因为风格变化隐藏本机OSHI异常。

每次更新完成后按 conventions.md 第10节提交Git。当前所需PD API均已存在，无新增API请求。

## 第59轮法杖风格

用户最新要求覆盖第58轮写实外观与细弧流。法杖使用有明确分面的低模几何、宽托架和有限细节；颜色离散，游戏面光照统一。idle改为大颗粒组成的两枚悬浮菱形符印，充能柱固定在脚下，不以小粒子填充细弧。见[wand-casting.md](wand-casting.md)。

## 第60轮状态语义与模块动画

法杖继续使用分面低模和实色大颗粒；扩展悬浮侧晶/聚焦叶片等独立模块，以原生物品模型帧表示idle，主宝石四档亮态表示真实施法后的余能。白色束印回位是施放恢复，蓝色导晶充盈是法术序列充能；装备/退场压缩，不再使用不明含义橙色柱。见wand-casting.md。

第61轮继续保持实色方粒；尺寸寿命曲线代替固定尺寸到期删除，透明度保持1。护盾单片起落不把整个面板缩向球心。当前规则和证据见[动画连贯性](animation-continuity.md)。

第63轮：当前43张卡牌，集束炸弹移除；双重施放使用两张错位叠放的卡牌与抽出箭头。爆炸不再全套统一球/蓝环，MC大块实色片元分别承载火舌、余烬、烟尘、晶体碎片。
