## 范围与定价

参考 Noita 的可组合投射物、陷阱与改变施法位置的思路，新增七张卡；属于本模组改编，不复刻原作的伤害、穿墙或地形破坏。

## 接入机制

- `Projectile.launchDirection` 在乘自身速度之前保存原始施放方向；静止法术与触发荷载不会因 `speed=0` 丢失来向。
  `Velocity` 接受原始向量的副本，避免对调用者/兄弟荷载的共享向量原地乘速。
- `LongDistanceCast` 在 onActive 的 SETUP 之后前移出生点；不修改玩家位置。
  碰撞子步点可能深入方块表面不超过1/16格：若出生点在碰撞箱内部，只允许沿荷载来向修正至相邻1/8格的空气。
  起点仍在实体方块内部时继续被截断，不以此穿过整块墙。
- `Projectile.motionEnabled` 让粘附水晶和已命中的电弧停止 Move 积分；命中后的子步循环也立刻停止，防止同tick重复碰撞再次杀死电弧。
  `ConstantAcceleration` 对停止积分的投射物不积累无用速度；轨道 OVERRIDE 可继续决定位置。
- `CrystalReaction` 的爆炸通知只将水晶排入3–4tick预警，不递归执行爆炸，不修改 MagicManager 正在遍历的列表。
  多次通知幂等；超量淘汰、自然过期或录制清理不引爆水晶。爆炸可以激活其他施法者的水晶，专用引爆术只选择自己的。
- `ChainArc` 每次施法持有独立命中UUID集合，按距离和实体id确定下一目标；只跳向活着、非施法者、非盟友、未命中的可见生物。
  被护盾挡下或目标不接受伤害时终止跳跃，不继续绕过护盾。
- `PlasmaBeam` 在 VISUAL 阶段读取束源最终位置，光束射线先被方块截断，再查询该线段穿过的生物。
  每次伤害使用真实线段来向问护盾，最多选最近4名目标；束源碰方块或正常到寿后10tick线性淡出。
- `DirectDamage` 向能量盾声明单次直接伤害强度；`Hurt`、`ChainArc`、`PlasmaBeam` 实现同一契约。
  `SpellDamage` 统一护盾兜底、原版无敌帧临时清零/恢复、实际接受伤害后的冻结。
  爆炸仍走原来的爆炸护盾入口，抵扣成功时不碎冰。
- `FrozenStatus` 使用命名的瞬态移动速度属性修饰器，而非覆盖迟缓药水；限制水平移动和上跳、保留下落及转向/攻击。
  到期、碎冰、死亡、跨维度或服务器停止时移除属性与表现；免疫表40tick后回收，不写入存档。
- 新法术捕获施放维度；施法者跨维度时新水晶、束源和斥力场清理，不将旧坐标映射到新维度。

## 表现与资源

全部法术粒子由 ParticleDrawing 1.0.14 提供：水晶192颗柔边点描棱并自转/脉动，激活后变为暖色；
电弧每跳160颗折线光点、8tick淡出；束源120颗青蓝光点，表达式逐帧求值线段与亮度，10tick线性退场；
斥力场三条球面大圆共288颗橙色点、8tick退场；冰冻64颗跟随实体的青蓝冰壳、6tick退场；远距施放48颗符文环、8tick淡出。
水晶/斥力场静止时不更新轴心；移动时更新组轴心。光束更新端点变量；本模组不持有粒子位置、速度或句柄表。
PD 拒绝生成部分粒子时只降质，不影响伤害/碰撞/状态。现有 API 足够，无新增 API 请求。

七套物品定义/模型/64×64透明PNG与中英文名称、描述齐全。图标沿用现有圆形底牌，使用原创像素符号；
可用 `python tools/spells/generate_icons.py` 重建，不引用 Noita 的图像资产。

## 推荐装配

- `触发火球 → 休眠水晶`：把水晶送到命中点；另用水晶引爆结束布置。
- `黑洞` 与 `连锁电弧` 分别施放：聚怪后让电弧在敌群之间跳跃。
- `远距施放 → 黑洞/重力场/等离子束`：改变场或束源出生位置。
- `触发火球 → 远距施放 → 黑洞`：荷载继续沿命中反弹来向前移，不读取摄像机方向。
- `周身环绕 → 等离子束`：束源沿轨道移动、光束沿切向扫动；仍有2秒硬上限。
- `冰冻附魔 → 火球`，再单独施放普通火球或爆炸：先控制，再触发一次碎冰。
- `斥力场` 与慢弹分别施放：影响双方弹道；不能当成保证格挡的护盾。

## 第63轮当前覆盖规则

电弧不再固定最多3跳，每5刻索敌至真实maxAge耗尽；首次命中速度×4决定范围，延寿/速度修正分别增加次数/范围。等离子束默认初速0、基础40刻，延寿可增加真实寿命；动态束端点使用PD直接样本插值。轨道修正改为GUIDANCE并经过Move碰撞扫掠，放大半径依速度变化。当前实色块状视觉、碎裂退场与量子复制体判定见[spell-quality.md](spell-quality.md)第63轮。所有时间提示使用刻。
