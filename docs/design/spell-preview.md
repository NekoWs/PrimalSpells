# 法术链预览与悬浮编杖

## 使用

在原版背包或箱子菜单中，空手右键法杖，或悬停法杖按V，打开可拖动的悬浮编辑窗。原容器仍可操作：从背包拿起散卡，再点击悬浮槽装入/替换；空光标点击已占用槽取出一张卡。点击标题栏拖动，右上角关闭或Esc先关闭窗口；关闭菜单/断线也清理窗口。旧滚轮选槽保留兼容，后续是否移除另定。

默认18格以内法杖按9列显示。悬浮窗内滚轮浏览当前施法树，紫色◇为根链、青色↳为独立荷载，缩进表示复制/追加控制展开；×表示该牌未付费。上方数字表示预演后的MP、施放延迟、充能时间与根投射物数。点击悬浮窗数值行↗，或手持法杖在游戏中按V，打开完整只读预览，显示作用于每个投射物的实际已付费修正、作用域路径和失败原因。

## 权威语义

Wand.preview在独立的牌堆、卡牌和法力副本上直接调用Wand.drawChain/payChain/discard；没有第二个解析器，不调用spell、onActive或粒子/世界入口。先记录真实展开树，再按真实付费结果标记，追加系列免费修正同样来自原抽牌路径。复制单卡节点与其展开保留层级，触发/追加荷载使用独立scope，本链修正与顺序无关；尚未成功付费的修正不会列入投射物配方。预览不保存NBT或驱动运行期钩子，不改变当前牌堆/MP/冷却。

服务端回报当前下一次抽牌，而不是假设从槽位0重新开始。编辑装卸与旧规则一样重建牌堆。预览每10t刷新，请求限流5t，展示最多4096行；超长施法树不适合本界面。冷却/MP失败会显示，部署法术的世界命中结果不在预览范围。

悬浮装卸包包含当前菜单id、菜单槽位、wandId和法术槽位。创造物品栏光标遵循原版由客户端选取卡片，额外提交已注册散卡id与合法数量；服务端不接受任意物品组件，生存模式禁止该入口。服务端验证菜单、真实物品、拾取权限、容量及光标散卡；不接受客户端提交法术列表或任意物品内容。复用原WandItem装卸入口及原菜单光标同步；不在客户端执行装卸。堆叠卡只消耗一张，替换出的旧卡优先回到光标或背包，背包满才沿原版掉落回交，不吞掉整叠卡。

S→C预览经ClientPayloadSink，双向包客户端处理器由NeoForge26.2的RegisterClientPayloadHandlersEvent注册。协议1.2.0，客户端和服务端同时更新；不修改wandId/法术id/NBT键。

## 材质包

默认采用原版容器的灰色硬边倒角、内凹槽与浅金选择框。资源包可以直接覆盖以下贴图，无需改代码：

- `assets/primalspells/textures/gui/sprites/wand_editor/panel.png`：24×24，九宫格边框4像素；对应panel.png.mcmeta保留gui.scaling九宫格声明，中心随窗口拉伸。
- `assets/primalspells/textures/gui/sprites/wand_editor/slot.png`：18×18内凹槽。
- `assets/primalspells/textures/gui/sprites/wand_editor/selected.png`：18×18透明选择框。

文字走语言资源、法术图标走既有物品模型，均由资源包统一替换。窗口外观不通过硬编码位图或PD粒子绘制。

## 实机验证

foundations验证只读性、父子链修正隔离、复制单卡而非法术链、多种控制牌、MP不足、预览与真实出手费用/双冷却一致，以及真实网络回报。悬浮编辑补测真实菜单光标取卡/装卡、换卡回交旧卡、创造伪造堆叠数量拒绝及伪造wandId拒绝。散卡目前不可堆叠。既有spell_chain维持76项真实机制回归；最终证据见build-and-run第83轮后续记录。

展开完整预览时复用悬浮窗最近一次服务端结果，随后照常请求刷新，避免请求节流造成短暂空白等待；不进行客户端解析。V可在按键设置中改绑，容器内同样使用改绑后的键。

最终foundations 27/27通过，包含生存装卸、拖动及打开完整预览，260帧零丢帧；具体证据及环境日志限制见build-and-run。
