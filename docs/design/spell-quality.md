当前用户口径：保留MC硬边像素、不透明有限色阶；表现力优先，面向高配电脑。
图标已获认可，本轮不重画。用户授权修改既有机制以实现修饰/投射物联动。
本文件接续 [minecraft-visuals.md](minecraft-visuals.md)，覆盖其中第53轮的简化造型和“不改变机制”。

## 动作与材质

| 效果 | 当前表现 |
|---|---|
| 护盾 | 受击晶格保持球壳尺寸，面心裂纹与局部冲击圈；破裂碎片沿法线/爆炸方向剥落受重力。破口轮廓跟人，碎片留在受击处。无整罩缩小 |
| 爆炸 | 3tick白热闪爆、八瓣火团、三向快速冲击圈、密集喷射碎片；第2/5/9tick分时生成灰色翻涌烟团，配镜头重音。触发即伤害，不增加蓄力 |
| 休眠晶体 | 三根倾角/高度不同的六面长柱与尖顶，晶面用不同实色，表面少量闪屑；激活变暖、爆裂成紫/冰色晶屑。不是旋转菱形线框 |
| 电弧 | 冷白主干、青蓝分叉与端点溅射；离散寿命闪烁，跳跃线段也能击中晶体 |
| 等离子束 | 白热主芯与双层螺旋能量流，坐标1/32格离散；束端溅射，退场沿切线散开 |
| 冰冻 | 保留冰壳，破冰沿球面喷出固定尺寸冰片；自然解冻是较弱碎冰 |
| 斥力场/重力场 | 保留稳定场结构与位置跟随，增加外推冲击圈/终止波与碎屑，退场不用整组缩小 |
| 黑洞 | 小暗核、六臂双层吸积盘、更密的吸入星尘；移动外环继续保留滞后椭圆。吞弹后周期吐出能量圈 |
| 普通弹/召唤/远距 | 共用出生冲击、修饰共鸣火花、命中喷射；传送两端以紫色断环和碎屑表现；无人机召唤有环形出场和蓝色碎屑 |

全程用ParticleDrawing公开的Draw、ParticleGroup、ParticleBatch、ParticleVisual和有限寿命；
PixelVfx只构造几何/初值，未增加自有粒子引擎、渲染器或PD替代实现。

高配档通过PD现有配置设置维度100万/每人10万/客户端20万粒子，渲染同步批次65536；
启动服务端和首个客户端tick时应用，不关闭容量保护，不改PD jar。原默认每人2万会截断多枚晶体的晶面。

## 配方与后代

`SpellAssembly.apply`是法杖和触发荷载的装配入口；每个投射物保存修饰id计数与原始抽牌顺序，实际effect独立克隆。
弹跳复制、集束、定时爆炸弹、纠缠复制和触发荷载继承非生成型修饰，重新结算基础数值，
不复制已乘过的运行时状态；加法/乘法修饰按原顺序重放，子弹初速抵消基础speed和速度卡的重复倍率。生成型（复制/集束/定时发射/纠缠/双发）不传给后代，避免无限自我繁殖。
无人机把相同非生成型有序配方写入实体NBT，之后无人机弹继续装配；存档重载保留配方。

| 修饰族 | 扩展接入 |
|---|---|
| 速度/重力/追踪/轨迹/环绕/弹跳 | 原运动effect作用于弹体；静止源装运动卡后初速0.25，瞬时炸弹寿命至少40，成为可飞场源/炸弹；集束/弹跳复制也激活静止源，定时发射使瞬时源至少存活40tick |
| 扩散/聚爆 | 同时影响爆炸参数、弹体视觉尺寸、晶簇尺寸、碰撞体积、场半径、光束长度/宽度、电弧跳跃距离；倍率分别2/0.5 |
| 伤害加强 | 直接伤害和爆炸伤害各+3；原本无直接伤害的场源装伤害/冻结后每10tick近距离共鸣攻击，辅助投射物命中实体也结算附伤/冻结 |
| 易爆/去爆/弹跳爆炸 | 易爆使无爆炸本体获得命中/死亡爆炸，伤害×2；去爆将半径归零；终止命中不会与死亡重复结算，存活弹跳可重复爆炸 |
| 延寿/穿透 | 光束采用实际maxAge，穿透束不再被墙截断且不限制四个目标；原普通弹接入保留 |
| 护盾 | 除持杖者被动盾外，修饰弹体在一格内反射入射敌方魔法弹并改变归属；同步effect施法者 |
| 冰冻/玛纳 | 爆炸、直接弹、电弧、束、场源共鸣统一接入冻结；直接命中玛纳弹每张额外回蓝2，不超过法杖上限；施法时原返蓝30仍保留 |
| 双发/生成/远距 | 抽牌双发保持；后代继承和零方向兜底已接通；远距相对各次真实释放点执行 |

数值仍按牌序执行：扩散伤害×0.5、易爆×2抵消，故“小爆炸+扩散+易爆”为半径6/伤害12。
冻结削减直接伤害至75%，爆炸伤害独立，不额外乘75%。

## 跨法术反应

- 引爆术把自己的非生成型配方传给已布置晶体，扩散/聚爆还改变引爆搜索范围。
- 普通弹扫掠、电弧跳跃、光束有效线段击中晶体：每个入射弹只充能一次，增加储能和爆炸伤害，继承入射冰冻并进入3tick引爆倒计时。取消每人24晶体的旧截断。
- 冰弹与热弹（火球/触发火球/激光/等离子束源）近距离接触：双方消耗，产生蒸汽喷射和冰蓝冲击圈。
- 黑洞接触普通弹：吞掉弹体、储存伤害能量，结束时释放储能爆炸；场源之间牵引但不互吞。
- 爆炸冲击真实改变附近魔法弹速度；晶体爆炸通知仍只标记倒计时，下一tick结算，避免递归爆炸。
- 所有反应限定同一维度；受护盾拦截的伤害不能冻结目标。
