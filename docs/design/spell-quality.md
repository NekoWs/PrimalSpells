# 法术质感与联动

## 表现语言

保持MC硬边、实色大颗粒与明确轮廓。各法术按机制设计动作，不共用同一个装饰圈。片元尺寸燃尽应接续运动，不能把爆炸/破碎倒缩成球。

| 效果 | 当前表现 |
|---|---|
| 爆炸 | 随机选择外散火团、双向喷流或上翻火冠；每束共享轴向与分叉，白热前锋、橙红厚边、少量弹道余烬，烟团沿火舌翻起；无外侧蓝环，无先蓄力再伤害 |
| 水晶 | 青金双尖四棱晶体、琥珀腰棱，外向晶面；临爆加速白闪后向外爆碎，冻结保留冰蓝 |
| 护盾 | 稀疏受击晶格和少量独立外飞碎片；不整罩缩小，无三条中心线或额外冲击圆环，破口轮廓跟持有者 |
| 链锯 | 沿实际方向的单道随机弧刃，7～9片锯齿，随机刃面/曲向/长度/弯度；3～4t逐片熄灭，高频不固定为米字 |
| 连锁魔弹 | 白芯青色四齿本体、两跳之间收拢蓄电、本次跃迁电流；没有停在旧命中点抖动的白长尾 |
| 等离子 | 可辨识束源本体、白热主芯与能量流，视觉只到实际墙/护盾截点；移动时本体和束共用位置 |
| 汇聚之光 | 原地金白镜阵10t合拢，轴向光矛预示固定方向；发射后镜阵后退/张开再收片，反向排光，不追加第二次人物后坐力；主芯真实照明逐渐升亮、释放时收束；射出每刻64格，以连续光脊瞬时贯穿常见射程 |
| 锯片 | 紧凑厚齿钢盘，自带下坠、旋转/反弹与少量接触火星，失效向外金属碎散 |
| 延迟载体 | 随本体移动的绿核心与六枚锁印，到真实释放当刻才打开，强制清理不伪装成触发爆开 |

大小爆炸用不同火舌数量/尺寸/速度和错峰寿命。普通爆炸在金黄、琥珀与朱红色阶中独立取样，晶体保留玉绿/金色；宏观主方向、长短、分叉、宽度和寿命均变化。轮廓持续外扩，仅单片熄灭。每次出生只提交两批火舌/碎片与一批延后烟团，大爆炸至多177片，避免上千片重叠形成同质球壳。不可变尺寸曲线和基础材质共享，运动与回收仍归PD，不实现自有预算/插值/粒子管理器。性能口径见[原生基准](performance.md#爆炸表现)。

高频火花/触发/无人机弹去掉周期共鸣喷发，命中与死亡少量方屑；经济修正不放大碎屑或将它们染绿。

[随机爆炸与八发压力的实机动画](references/explosion-variants.gif)来自explosion_performance原生录制。单发爆炸另检查实际伤害、50%→5%覆盖量退场与结束零粒子；晶体到期和全目录光照使用独立回归，不以减少粒子数代替视觉验收。

## 修正与后代

SpellAssembly统一装配同链修正，按ID规范化，无牌序语义。独立触发荷载只使用自身链修正；同源弹跳/纠缠/定时复制重建非生成配方及独立荷载，不复制已经乘过的运行态。

- 速度/重力/轨迹/追踪/环绕作用真实运动；追踪前方选靶，穿透当刻沿当前切线渐入新目标的曲率，光束沿真实路径成弧；静止源装运动卡后可飞，瞬时源延长到可运行窗口。实际命中仍走Move。
- 扩散/聚爆联动爆炸、弹体/晶体尺寸、碰撞、场/束/电弧范围；伤害加值与倍率按规范配方结算。
- 伤害强化同时影响直接/爆炸伤害；易爆可赋予非爆炸弹真实爆炸，去爆归零范围；终止命中和死亡不重复爆炸。
- 光束寿命读取实际maxAge，穿刺解除墙/普通目标数限制并开启自伤；冻结只在实际接受伤害后施加。
- 无人机保存非生成配方到NBT，后续弹继续独立装配。生成型修正不递归继承，避免无限复制。

## 跨法术反应

水晶被真实扫掠、电弧/束段击中时，每个入射实例只充能一次，增加储能/伤害、继承冻结并进入短引爆倒计时。引爆卡将非生成配方传给自己的晶体；爆炸可通知其他所有者晶体，但不递归修改当前遍历列表。

冰/热弹相遇产生蒸汽反应；黑洞吞普通弹储能并在结束释放，场源不互吞；爆炸按强度推离附近魔法弹。所有反应限同维度，盾抵消的伤害不能冻结。

机制与数值见 [战斗规则](combat-pricing.md)、[特殊法术](spell-expansion.md)。原生玩法、实际视觉与清理分别验收；particle_lighting已验证基础光照收束，所有法术的显式生命周期覆盖与机枪等混合退场未过项见 [open](../issues/open.md)。
