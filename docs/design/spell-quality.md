## 配方与后代

`SpellAssembly.apply`是法杖和触发荷载的装配入口；每个投射物保存修饰id计数与原始抽牌顺序，实际effect独立克隆。
弹跳复制、集束、定时爆炸弹、纠缠复制和触发荷载继承非生成型修饰，重新结算基础数值，
不复制已乘过的运行时状态；加法/乘法修饰按原顺序重放，子弹初速抵消基础speed和速度卡的重复倍率。生成型（复制/集束/定时发射/纠缠/双发）不传给后代，避免无限自我繁殖。
无人机把相同非生成型有序配方写入实体NBT，之后无人机弹继续装配；存档重载保留配方。

| 修饰族 | 扩展接入 |
|---|---|
| 速度/重力/追踪/轨迹/环绕/弹跳 | 原运动effect作用于弹体；静止源装运动卡后初速0.25，瞬时炸弹寿命至少40，成为可飞场源/炸弹；集束/弹跳复制也激活静止源，定时发射使瞬时源至少存活40tick |
| 扩散/聚爆 | 同时影响爆炸参数、弹体视觉尺寸、晶簇尺寸、碰撞体积、场半径、光束长度/宽度、电弧跳跃距离；倍率分别2/0.5 |
| 伤害加强 | 直接伤害和爆炸伤害各+3；原本无直接伤害的场源装伤害/冻结后每10tick近距离共鸣攻击，辅助投射物命中实体也结算附伤/冻结 |
| 易爆/去爆/弹跳爆炸 | 易爆使无爆炸本体获得命中/死亡爆炸，伤害×2；去爆将半径归零；终止命中不会与死亡重复结算，存活弹跳可重复爆炸 |
| 延寿/穿透 | 光束采用实际maxAge，穿透束不再被墙截断且不限制四个目标；原普通弹接入保留 |
| 护盾 | 除持杖者被动盾外，修饰弹体在一格内反射入射敌方魔法弹并改变归属；同步effect施法者 |
| 冰冻/玛纳 | 爆炸、直接弹、电弧、束、场源共鸣统一接入冻结；直接命中玛纳弹每张额外回蓝2，不超过法杖上限；施法时原返蓝30仍保留 |
| 双发/生成/远距 | 抽牌双发保持；后代继承和零方向兜底已接通；远距相对各次真实释放点执行 |

数值仍按牌序执行：扩散伤害×0.5、易爆×2抵消，故“小爆炸+扩散+易爆”为半径6/伤害12。
冻结削减直接伤害至75%，爆炸伤害独立，不额外乘75%。

## 跨法术反应

- 引爆术把自己的非生成型配方传给已布置晶体，扩散/聚爆还改变引爆搜索范围。
- 普通弹扫掠、电弧跳跃、光束有效线段击中晶体：每个入射弹只充能一次，增加储能和爆炸伤害，继承入射冰冻并进入3tick引爆倒计时。取消每人24晶体的旧截断。
- 冰弹与热弹（火球/触发火球/激光/等离子束源）近距离接触：双方消耗，产生蒸汽喷射和冰蓝冲击圈。

## 第64轮：延迟施法与链锯

延迟载体不再用Trajectory的漂浮绿尘和自动拖尾寿命。实色浅绿核心配六枚绿锁印，一直随载体移动并逐步收拢；仅真实寿命到期时在最终位置打开锁印、飞散绿/白片元，同时生成后续法术，尾迹不会继续作为移动本体。强制清除时只用2刻片元收尾，不爆开、不放荷载。取消DelayedCast/Chainsaw上的通用飞散共鸣，避免错误语义。

链锯是近距白/金锯齿切割脉冲，三组硬边切痕分别向侧/上/斜向打开，5刻熄灭，无渐变透明；图标由现有像素卡生成器绘制。延长存在时间后每2刻在当前最终位置追加一次切割，保留加速/伤害等修正的真实移动和命中。

本轮追加：删除球形环绕；周身环绕半径为`clamp(2+实际驱动速度×0.5,2,6)`，降低加速卡导致轨道突然过大的幅度，仍用GUIDANCE/Move真实扫掠。

晶面三角形顶点绕序修正为朝外：上面`b,a,top`，下面`a,b,bottom`，局部+Z与PD非广告牌四边形的外向正面一致；保留原生XYZ弧度spin，无双面复制或自建渲染器。寿命最后40刻白色闪烁，白/绿或白/冰蓝的半周期为`ceil(剩余刻/8)`并钳制1～5刻；引爆倒计时也进入同一剩余时间口径。每次颜色切换用PD原生1刻recolor接续，不瞬间跳变。自然到期调用唯一detonate入口，爆炸伤害和连锁通知真实执行；强制清理/跨维度取消不额外爆炸。

## 第65轮：体积火舌、分段魔弹与危险法术

爆炸将均匀火星云改为共享方向的厚像素火舌：多片横截面形成亮心/橙色主体/暗红厚边，0～2刻分批撕开；外缘高速长碎片穿出，稍后大块烟尘外扩上浮。大小爆炸的火舌数量、尺寸与速度不同，每次方向/缺口/片元寿命仍随机。各火舌切片的燃尽时间错开，大爆片元寿命18～37刻、末12刻用EASE_OUT熄灭，小爆寿命12～31刻、末8刻熄灭；每片先快速长出再熄灭，位置持续向外，不重新收成一个球；晶体保留玉绿/金色。原生PD批次速度/受力/寿命曲线执行运动，不用透明渐变或本侧播放器。

连锁魔弹用常驻白芯青色四齿本体和单次跃迁电流，四齿在两次跃迁之间蓄电收拢；没有在旧命中点抖动的长白拖尾。离散跃迁属于玩法，不用粒子插值掩盖判定，视觉最终坐标仍交给PD trackAll插值；终结4刻逐片收尾。玩法与数值见architecture第65轮和combat-pricing第65轮。

## 第67轮：白金聚焦与反冲反馈

汇聚之光用17枚实色硬边片元形成白金核心与四组棱片，20刻内逐渐聚向杖首；图案最大半径0.39格，外围单片3/32格，避免第一人称蓄能片占据准星。原生PD trackAll负责位置接续。释放时最后杖首的棱片3刻收尾，宝石短亮，光束从最后蓄能点连接实际Move扫掠终点，反弹段仍读取真实位置。白色光脊与两道金色侧线在空间上分开，粗像素线保留12～14刻错峰余辉，不用半透明渐变。直接蓄能可转向，发射方向以释放瞬间准星为准。
