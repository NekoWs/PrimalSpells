# 持杖法阵、宝石施法与法杖模型（第58轮）

最新用户要求法杖独立于MC方块风格，具有魔法氛围与高级材质；覆盖第57轮方块模型。法术卡和其他法术的MC硬边实色规范继续有效。

## 视觉与时机

切出法杖预热16tick（0.8秒），三角法阵从三个顶点沿边展开，半径1.2格，离地0.06格。
汇聚由六束长弧光流组成，每束240个连续采样点；随机起点均匀分布在三角形内，随机控制点形成外展、上扬、内收的三次Bezier曲线。周期1900–2600ms错开，每轮更新起点和弧向。头部加速、尾部逐渐收细，青蓝到白的实色变化，不使用透明渐变或柔光圆点。固定随机种子由玩家UUID、束序号和轮次确定，不逐帧抖动。
白色施放间隔沿外缘推进，完成后分段抬起收细；琥珀充能线内收并在完成后汇入宝石，两种收尾均400ms加最多120ms错峰。切杖或放下冻结各束当前循环、余流按200ms错峰开始收束并在550ms内汇入，避免周期重置让尾迹突然消失，三角边线抬起消失；750ms退场，16tick由PD销毁。死亡、跨维度和登出立即取消。
成功施法时宝石播放一次400ms的短促迸发，多重施法只播放一次，没有额外延迟。常驻5组1657颗粒子（96边+1440流+60延迟+60充能+1焦点），施法另有64颗短命粒子。

## 原创法杖

真实立体OBJ网格：20面旋切深色杖身、靛色皮革握柄、雕金束环、双螺旋金线、四根错高的流线托爪，以及八面长切面星辉宝石。细托爪留出负空间，取代旧模型厚重金杯。调试杖及t1–t6共享模型，避免材质变色破坏整体质感。
原创材质由内置imagegen绘制，保留原图，不裁切或后处理。资源textures/item/wand_atlas.png是四等分图集：左上深蓝黑曜石、右上雕花香槟金、左下蓝紫晶体、右下靛色皮革。源提示词和生成方式见docs/design/wand-materials.md。
通过NeoForge内置neoforge:obj加载，无自制模型或粒子渲染器。tools/wands/generate_models.py生成wand.obj/wand.mtl及7个wand*.json；几何单位为格，JSON显示变换以16单位计。库存、双手、掉落和展示框均配置。
第三人称使用0.5显示缩放，通过官方枚举扩展提供单手抬臂姿势WandArmPose；抬臂角度根据俯仰与宝石高度求解，握柄进入手心，杖轴与前臂交叉，另一只手可独立动作。枚举参数独立于模组初始化；仅客户端类读取该姿势。

## 宝石位置与准星

真实投射物、汇聚终点和迸发共用WandCastingFx.origin：

`眼睛 + 视线×0.85 + 视线上方×0.25 + 手侧×0.38`（格）。

上方向由视线与yaw正交基计算；副手和左惯用手镜像。第一人称模型中心(8,23.4,8)配套；WandHandPose以tan(35°)/tan(世界FOV/2)补偿原版固定70°手持投影。
WandAim从眼睛沿准星射线取128格内最近目标：实体真实碰撞箱与方块COLLIDER，方块遮挡后的实体不会被选中，流体不挡瞄准射线。不命中时取远端。随后从宝石朝该点归一化发射；施法迸发使用同一方向。这里仅校准发射方向，散射、重力、蛇形等修饰器仍按其机制继续改变弹道。
WandItem按WAND_ID判断重新装备：同一根杖的数值/组件同步不再触发物品上下跳；换槽、换杖和换物品仍播放正常装备动画。原版走路/受伤晃动仍属于客户端手持变换，服务端不读取某一客户端矩阵。

## PD目标与能力

A目标：实体锚定的随机长弧光流、连续细尾、真实冷却与有限退场。
B现有能力：ParticleGroup.expression/defineEntity/setVariableLive/destroyAfter以及实体getter可逐帧求Bezier、宽度和颜色，足够覆盖本次目标。
C降级：无新降级或API缺口。不维护自制粒子积分器、发射器或寿命引擎。服务端只维护持杖会话、冷却和退场取消点；播放与成员销毁归PD。
此前PD批量速度包超过512的黑洞缺陷仍登记在issues/pd-api-requests.md，本轮不改那个接入点。
