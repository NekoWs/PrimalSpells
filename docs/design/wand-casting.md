# 持杖法阵与施法表现（第56轮）

## 视觉与时机

- 切换到法杖后固定预热16tick（0.8秒），三角法阵从三个顶点同时沿边铺开；前12tick绘制法阵，随后建立汇聚点。
- 主色为青蓝/浅青实色方粒，法阵半径1.2格，脚底抬高0.06格；不使用透明度渐变、加色、柔边贴图。
- 待机的三束细粒从三角顶点沿弯曲轨迹持续汇聚至杖前，位置与朝向用PD公开实体getter逐渲染帧读取。
- 施法点：眼睛高度下移0.12格，沿视线前推0.6格，侧移0.22格；侧向按实际主/副手和左右手设置选择。持杖的实际弹体出生点使用同一个公式。
- 施法时直接发射；移除SpellResonance出生时的小环，不播放新的发射闪环或重复展开法阵。弹体本身、拖尾、命中表现继续正常工作。
- 施放延迟：三角外侧白色进度边推进。充能延迟：三道琥珀色径向线向内收拢。两者可同时出现，读取真实delay/recharge及lastDelay/lastRecharge；汇聚粒子在冷却时变细，仍保持待机运动。
- 持续施法不重启装备动画；换杖、放下后重新拿起、换维度和重生重建法阵。死亡/登出/服务器停止立即移除永久粒子组。
- 双持只显示一座法阵，使用中的手优先，否则主手优先。

## 运行时边界

WandCastingFx位于magic/effect/visual，维护玩家持杖会话；WandManager的服务端Pre tick驱动，load/stop与登出路径清理。
一次会话为5个PD组，共253颗永存实色方粒（96边、36流、60延迟边、60充能线、1汇聚点）。位置和形变交给PD表达式，本侧仅更新冷却进度、眼高与手别变量；不维护粒子积分/同步引擎。
Wand.spell在抽牌、扣法力之前检查装备预热；未完成不消费牌堆和法力，也不改原delay/recharge。非玩家/未实际持有该杖的直接配方调用仍按原入口运行；被动法术不受主动施法预热阻塞。
这16tick是临时持杖会话状态，不写NBT，也不混入法杖等级的施放延迟或充能时间。

## 黑洞

移除BlackHoleFx的两层椭圆外环、核边光环、储能环以及仍像同心环的固定螺旋吸积盘；只保留暗核、稀疏边界星点和吸入星尘。移除相关表达式、滞后参数与退场逻辑。
黑洞星尘的既有PD批量速度包缺陷没有改变，仍见issues/pd-api-requests.md；不把删除装饰环声称为修复该网络错误。
