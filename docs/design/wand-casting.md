# 法杖施法表现

## 脚下三角形

持杖预热8t，三顶点同时沿边绘制，主边与角点短入场。主边保持平面，青色亮点沿边巡行；角点只做轻微尺寸/半径呼吸，不逐颗上下波动。

全层通过PD的defineEntity和实体getter实时跟随玩家；朝向不读yaw/pitch，以 `theta=PI/2+lane×2PI/3+now×0.00015` 慢自转，周期约838t。新冷却层继承持杖会话时钟，不能各自重新起相位。

| 层 | 状态引导 |
|---|---|
| 白色内边束印 | 施放间隔，亮段从顶点逐步收回；75ms展开、完成后150ms缩片 |
| 蓝色外边导槽 | 牌堆充能，三边由顶点同步充亮；75ms展开、完成后175ms并回主边 |

状态来自服务端真实结算，立即发布。新施法创建独立提示，旧会话正常收尾。所有组透明出生，首次PD程序接管同时给位置、零尺寸与实色，避免切杖首帧满尺寸。

放下时presence做8t线性退场、片元尺寸presence^0.75，再retire等待PD完成；退场仍跟随玩家。有限冷却表达式保留7t清理余量；登出/死亡/换维直接清会话。阵列使用不透明硬边方片，免环境光但不向世界发光。

## 模型与视角

分面低模原生OBJ/MTL组合：稳定握柄/托架、32帧侧晶与叶片idle、主宝石16级余光。idle周期48t；成功施法1t升亮、6t收尾，重复触发从当前亮度接续。主宝石/真实出生锚点不跟模块浮动。

WandArmPose负责第三人称手持，WandHandPose补偿FOV与原版物品投影。不再在眼睛附近摆浮动符印，避免第一/第三视角错层。资源生成见 [模型](wand-materials.md)。

## 出生点与瞄准

发射点为 `眼睛 + 视线×0.85 + 视线上方×0.25 + 手侧×0.38` 格；副手与左惯用手镜像。WandAim从准星取64格内最近实体箱或COLLIDER方块，再由宝石指向该点；墙后实体不会被选中。

这是统一玩法出生点，不当作第三人称手骨锚点。长按不减速；相同WAND_ID组件同步不重装备，成功使用回调不清持物高度，真实切槽仍有装备动作。

## 验证与限制

wand_casting及其第一/第三视角、宽FOV变体、wand_aim检查预热、跟随、自转、状态时序、模型余光、主副手瞄准和持物高度。冷却只在地面阵列及HUD表示，准心不重复显示菱形/进度条。

PD首次接管和变量完成回报已接入；未决光照与短粒子问题见 [PD需求](../issues/pd-api-requests.md)，不保留已失效的旧前置限制。
