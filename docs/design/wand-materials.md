# 暮紫封印法杖资源

采用已选定的[D版概念稿](references/dusk-seal-concept.png)：细黑曜杖身、紫黑分节握柄、骨白封印片、少量暗金连接件和紫色双尖晶体。杖首由一侧骨白折臂与另一侧黑曜脊柱构成，保留负空间；尾锥的小紫晶呼应主晶。各级法杖共用这一造型。

## 生成与材质

`python -B tools/wands/generate_models.py`重建原生OBJ/MTL、JSON组合物品和64×64图集`textures/item/wand_dusk.png`，不需要额外模型依赖或自制渲染器。图集按16px材质块确定性生成，使用硬边颗粒与固定色阶，不使用照片、柔和渐变或半透明表面；资源包可覆盖图集和模型。

主体399面，包含分面杖身、四条宽握柄缠带、窄束环、开放折臂与短尾锥。主晶中心固定在模型坐标(8,23.4,8)，六面环截面形成双尖紫晶。OBJ显式写出外向法线，凹轮廓先耳切三角化再封闭挤出，避免托架凹口和晶体内外面翻转。

## 待机与施法余光

三枚骨白封印片使用32帧、48t周期的低幅浮动与偏转，带正反两面的紫色浮印。杖身、托架与主晶保持稳定，idle不移动真实发射点；没有旧的悬浮侧晶或外扩叶片。

主宝石16级离散材质亮态，成功施法由WandCastPayload通知施法者及追踪观察者；WandModelProperty按wandId从当前亮度接续1t升亮、6t收尾，登出清缓存。使用原生composite与range_dispatch选部件/亮态，不替换物品栈、不重举法杖。

## 持握标尺

`wand/WandGrip.kt`统一保存世界出生偏移、模型宝石/握柄位置和第一/第三人称比例。生成器严格读取这些常量，从原版手持平移和宝石位置反解JSON变换；FOV补偿、服务端出生点与第三人称手臂姿势使用同一标尺。修改它后必须重新生成模型资源。

第一人称比例0.60，向画面中央轻倾12度；宝石降到画面下半部外侧。第三人称比例0.44，握柄中心对准掌心；手臂按新的主晶高度和杖长抬起。主副手与左惯用手镜像，姿态与实际瞄准见[持杖表现](wand-casting.md)。

## 验证

`wand_design`在原生户外背景展示右主手、右副手和左惯用手，并对紫晶实际像素检查下半屏外侧位置与中央留空。`wand_casting*`检查idle/余光、FOV和有限退场；`wand_aim`检查真实近远命中、遮挡及使用不重举。当前七场（wand_design、四个wand_casting视角、wand_aim、magic_hud）122项机制检查、1400帧零丢帧，材质/占屏和动画收尾门禁全部通过。证据在build/capture/out；复现方式见[构建指南](../build-and-run.md)。
