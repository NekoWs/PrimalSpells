# 非破坏性交互与寻法

主动生活法术和寻法罗盘提供非破坏性交互与真实探索定位。红石暂缓。

| 法术 | 行为 | 获取 |
|---|---|---|
| 显踪脉冲 survey_pulse | 12格内可见敌对Monster高亮120t，实体中心距离与方块射线共同筛选；不穿墙探敌 | ruins |
| 收纳术 item_pull | 收取施法玩家4格内可见掉落物，遵守拥有者/拾取延迟/容量和拾取事件；不替别的玩家整理背包 | starter、ruins |
| 轻羽庇护 feather_ward | 施法者获得200t原版缓降并清除当前积累的fallDistance | ruins |
| 瞄准 aim | 持杖免费被动，64格中央直线、1/64格细光丝；方块截断、最近实体原版轮廓；重复卡只显示一条 | starter、ruins |
| 火把 torch | 原有被动环绕光源，持杖时照明 | starter、ruins |

三张主动卡各走原抽牌、MP、冷却和荷载边界，依次12/8/15MP、8t施放延迟，无充能加值，静止短命符印。效果逐目标发UtilityAction；取消后不修改该目标。收纳只调用原版ItemEntity.playerTouch，不传送掉落物、不直接写背包、不清除原所有权或冷却。显踪不改变敌人AI/伤害，缓降不赋予飞行。其他攻击修正若由玩家主动组合，仍按原链语义装配，不把生活卡放入默认敌人攻击配方。

## 被动瞄准

瞄准从宝石施法位置朝准星目标追踪中央直线，不预测散射、追踪转弯、重力或反弹。实体先后顺序和方块遮挡由服务端射线决定，不会通过墙标记身后目标；本身不造成伤害，不消耗MP或增加冷却。非玩家持杖者同样可使用。

细线由PD组与原生变量缓动跟随端点，2t入场、3t收细，明确lightLevel=0以免改变屏幕照明。实体高亮通过AimTargetPayload短租约并入原版轮廓，保留原生发光和队伍颜色，不写药水效果或实体发光标记；多个施法者/法杖的租约互不撤销。放下、移除卡牌、死亡/换维清会话，断线或未续租时客户端自动清理。

## 寻法罗盘

村庄神殿入门奖励追加一只；也可用罗盘＋紫水晶碎片＋纸无序合成。默认外观使用原版罗盘动态指针，资源包可覆盖assets/primalspells/items/spell_compass.json及引用模型。入口、地点类别与示例法术在潜行右键提示中显示。

潜行右键切换当前维度可用的地点类别并清除旧目标；普通右键在64区块搜索半径内调用原版真实结构定位，给出坐标与约距离，并保存磁石指针目标。搜索200t冷却；没找到就清除旧坐标并提示换区，不制造虚假目标。搜索可能同步读取结构起点，范围和冷却用于避免连续触发，不能当作无限距离全图雷达。

| 类别 | 指向/目的 |
|---|---|
| 村庄·入门 | 五类村庄；神殿箱有入门杖，但不是每座村庄都有神殿 |
| 基础与轨迹 | 矿井、沙漠/丛林神庙 |
| 制导与防御 | 前哨站、沼泽小屋 |
| 触发与空间 | 府邸、要塞 |
| 爆破与穿刺 | 下界要塞、堡垒遗迹，仅下界 |
| 聚光与复制 | 远古城市/末地城，主世界或末地 |

罗盘定位的是有相关奖励/术士类别的结构，不保证指定单卡、箱子尚未开启或该地点尚有敌人。前往实际地点、战斗夺杖、回家拆改仍是获取闭环。自定义池可用数据包加入定位，无需新Java代码；可添加compass.primalspells.<池键>语言翻译，未翻译时显示池键。原寻法手记更新为原容器滚轮选槽与右键装卸、定位和流派应对说明。
