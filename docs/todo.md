# 开发方向

## 产品边界

核心模组负责法杖、法术组合、基础获取与持杖敌人；附属模组可增加敌人和结构。探索应有明确地点和可带回拆改的战利品，不能只依赖无指引随机开箱。

战斗魔法默认不破坏方块，敌人不拆机器/建筑。世界交互优先可恢复、可授权行为。

## 待办

- [ ] 法术音效：按用户要求后续统一设计施放、命中与弹跳等反馈；不再用史莱姆声作为弹跳占位音效。
- [ ] 红石联动：**用户明确暂缓**。后续先定义权限、循环触发、自动化与领地边界，再设计脉冲/施法器，不纳入当前工作。
